# DingClaw 中文后台信息架构

## 设计目标

后台不是“技术配置面板”，而是企业管理员可操作的控制台。

要求：

- 全中文
- 业务分区清晰
- 权限可见
- 风险动作可追踪
- 研发、运维、管理员、安全人员都能各看各的

## 顶层导航

建议采用左侧主导航 + 顶部全局栏。

### 左侧主导航

- 工作台
- 组织与身份
- 智能体
- 模型与中转
- 权限与策略
- 审批中心
- 审计中心
- 渠道接入
- 工具与集成
- 节点与浏览器
- 系统设置

### 顶部全局栏

- 当前环境
- 当前租户/组织
- 全局搜索
- 告警中心
- 当前登录人
- 快捷动作

## 角色视图

### 平台管理员

看到全部菜单。

### 部门管理员

默认看到：

- 工作台
- 组织与身份
- 智能体
- 权限与策略
- 审批中心
- 审计中心

但只看到所属范围的数据。

### 审计员

默认看到：

- 工作台
- 审批中心
- 审计中心
- 系统设置中的只读安全项

### 运维操作员

默认看到：

- 工作台
- 渠道接入
- 工具与集成
- 节点与浏览器
- 系统设置

## 一级页面设计

### 1. 工作台

定位：

- 管理后台首页

核心模块：

- 今日消息量
- 高风险动作数
- 待审批数量
- 失败任务数量
- 模型调用成本
- 渠道健康状态
- 最近安全告警

快捷入口：

- 新建 agent
- 新增模型中转
- 配置钉钉接入
- 查看待审批
- 查看风险日志

### 2. 组织与身份

定位：

- 统一身份中心

二级页面：

- 员工目录
- 部门目录
- 角色管理
- 用户角色分配
- 群组管理
- 身份映射
- 身份同步任务

关键能力：

- 搜索员工
- 查看组织树
- 查看某人在钉钉中的映射身份
- 查看某个群绑定了哪些策略
- 手动修复身份映射

### 3. 智能体

定位：

- 管理多个 agent

二级页面：

- Agent 列表
- Agent 详情
- Persona 配置
- 路由绑定
- 工具配置
- 沙箱配置
- 对话测试台

Agent 列表字段建议：

- Agent 名称
- Agent Key
- 类型
- 默认模型
- 生效范围
- 风险等级
- 状态
- 最近调用量

Agent 详情页模块：

- 基本信息
- 绑定规则
- Persona
- 系统提示模板
- 工具权限
- 会话策略
- 版本记录

### 4. 模型与中转

定位：

- 管理大模型供应商和模型路由

二级页面：

- 供应商列表
- 路由管理
- 模型测试
- 成本与限额
- 密钥与凭据

供应商字段建议：

- Provider 名称
- 类型
- Base URL
- 状态
- 默认模型
- 健康状态

路由字段建议：

- Route Key
- Provider
- Model ID
- Reasoning
- Timeout
- 适用 Agent
- 启用状态

### 5. 权限与策略

定位：

- 管理系统最核心的行为边界

二级页面：

- 策略集
- 路由规则
- 工具权限
- 数据范围
- Persona 规则
- 审批规则
- 灰度规则

策略编辑器建议分区：

- 规则名称
- 匹配条件
- 决策结果
- 优先级
- 生效范围
- 模拟测试

### 6. 审批中心

定位：

- 管理高风险动作审批

二级页面：

- 待审批
- 审批记录
- 审批流模板
- 审批人配置

待审批列表字段：

- 审批单号
- 发起人
- Agent
- 动作类型
- 风险等级
- 当前状态
- 创建时间

审批详情必须展示：

- 原始请求
- 触发上下文
- 工具参数摘要
- 风险原因
- 审批意见
- 执行结果

### 7. 审计中心

定位：

- 所有关键行为的取证与检索中心

二级页面：

- 审计事件
- 风险操作
- 工具调用
- 外发记录
- 浏览器证据
- 导出中心

筛选维度建议：

- 时间范围
- 用户
- 部门
- Agent
- 工具
- 渠道
- 风险等级
- 审批状态

### 8. 渠道接入

定位：

- 管理钉钉等接入渠道

二级页面：

- 钉钉账号
- 回调配置
- 群接入范围
- 触发规则
- 卡片模板
- 渠道日志

钉钉账号详情应包含：

- Client ID
- 凭据状态
- 事件订阅状态
- 默认策略
- 群接入概览
- 最近错误

### 9. 工具与集成

定位：

- 管理 OA、知识库、内部 API、浏览器兜底工具

二级页面：

- 工具目录
- OA 工具
- 内部 API 工具
- 知识库连接器
- 浏览器自动化模板

工具详情模块：

- 工具说明
- 风险级别
- 所需审批级别
- 调用范围
- 测试入口

### 10. 节点与浏览器

定位：

- 管理执行资源

二级页面：

- Gateway 节点
- Browser Worker
- Sandbox Runner
- 资源配额
- 故障与告警

建议展示：

- 在线状态
- 版本
- 当前任务数
- 最近心跳
- 最近错误

### 11. 系统设置

定位：

- 全局参数和平台治理

二级页面：

- 租户信息
- 安全基线
- Secret 配置
- 通知与告警
- 日志保留
- Feature Flags
- 操作记录

## 全局交互规范

### 1. 风险提示

以下页面需要显著风险提示：

- 工具权限
- 宿主机执行
- 浏览器自动化
- 对外发送
- 审批绕过

### 2. 配置变更

所有高风险配置变更都要：

- 有 diff
- 有操作人
- 有时间
- 可回滚

### 3. 测试入口

以下模块要带“测试”入口：

- 模型路由
- Agent Persona
- 权限规则
- 渠道接入
- 工具调用

### 4. 中文术语建议

- Agent: 智能体
- Policy: 策略
- Approval: 审批
- Audit: 审计
- Subject: 身份主体
- Claims: 身份声明
- Binding: 路由绑定
- Sandbox: 沙箱
- Browser Worker: 浏览器节点

## 首期必须做的页面

首期不必一口气做全，但这几页必须有：

- 工作台
- 钉钉接入配置
- 员工/群组/身份映射
- Agent 列表与详情
- 模型中转配置
- 策略管理
- 待审批
- 审计事件查询

## 不建议首期做的页面

- 可视化流程编排器
- 复杂拖拽式低代码规则编辑
- 多租户商城化能力
- 花哨但低频的图表面板
